01 📄
What is .env
  • .env is a plain text file in your project root
  • One KEY=value pair per line, no quotes needed
  • Your code reads it at runtime — never hardcoded
  • Lives only on your machine (or your server)
  • Never committed to git, ever
02 🚫
.gitignore Setup
  • Add .env to .gitignore before first commit
  • Also ignore .env.local, .env.prod, .env.*
  • Run git status — .env should never appear
  • If already committed, rotate your keys now
  • Use git rm --cached .env to untrack
03 📋
.env.example
  • .env.example is what you DO commit
  • Contains all the key names, no real values
  • Use placeholder values: your_key_here
  • Documents exactly what secrets a new dev needs
  • Keep it in sync when you add new keys
04 🐍
Python Loading
  • Install: pip install python-dotenv
  • Call load_dotenv() at the top of your script
  • Read with os.environ.get("KEY")
  • Use get() not [] — returns None if missing
  • Crash early if a required key is absent
05 🟨
Node / JS Loading
  • Install: npm install dotenv
  • Add require('dotenv').config() at entry point
  • Or use import 'dotenv/config' (ESM)
  • Access via process.env.KEY
  • Node 20+ can use --env-file=.env flag natively
06 🔄
Key Rotation
  • Rotate immediately if a key is ever exposed
  • Rotate on team member departure
  • Set expiry reminders for 90-day cycles
  • Exchange API keys: trade-only, no withdrawal perms
  • One key per environment: dev, staging, prod
07 🔍
Secret Scanning
  • GitHub scans repos and alerts on leaked keys
  • Install pre-commit + detect-secrets hook
  • Run git diff --staged before every commit
  • Search history: git log -p | grep -i "api_key"
  • Use truffleHog or gitleaks on CI
08 🤝
Sharing Code Safely
  • Share the repo link, not a zip with .env inside
  • Post code to Discord/Slack? Check for keys first
  • Paste to AI assistant? Redact all credentials
  • Screenshots can leak keys — check the frame
  • Use .env.example as the handoff artefact
// .env (never commit)
# Exchange credentials
EXCHANGE_API_KEY=abc123xyz_your_real_key
EXCHANGE_SECRET=supersecretvalue

# Notification
TELEGRAM_TOKEN=bot_token_here
TELEGRAM_CHAT_ID=123456789

# App config
ENV=production
MAX_POSITION_USD=500
// .env.example (commit this)
# Exchange credentials
EXCHANGE_API_KEY=your_api_key_here
EXCHANGE_SECRET=your_secret_here

# Notification
TELEGRAM_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id

# App config
ENV=development
MAX_POSITION_USD=100
// bot.py (reading the values)
import os
from dotenv import load_dotenv

load_dotenv()

# Crash early if key is missing
api_key = os.environ.get("EXCHANGE_API_KEY")
if not api_key:
    raise ValueError(
        "EXCHANGE_API_KEY not set"
    )

# Never log the key itself
print("Key loaded ✓")

The test before you share any code
"If I search this repo right now for my API key, will I find it?"
Run grep -r "EXCHANGE_API_KEY" . and check every hit. If a real value shows up anywhere outside .env, rotate that key before you do anything else.
