01 🛡️
Risk Controls
  • Stop loss on every position, exchange-native preferred
  • Max risk per trade enforced in code, not config
  • Daily loss circuit breaker with manual unlock
  • Cap concurrent positions, size, leverage
02 🛑
Kill Switch
  • One command flattens everything
  • Process kill in 10 seconds, no Googling
  • Exchange app fallback on your phone
  • Dead man's switch on missing heartbeat
03 📊
Monitoring
  • Push alerts for fills, stops, errors
  • Live dashboard for positions and P&L
  • Structured logs, rotated, machine-readable
  • Stale data detection pauses entries
04 🧱
Code Structure
  • Exchange behind an interface
  • Risk checks centralised, not per-strategy
  • Decide separated from place order
  • Same code path for backtest and live
05 🧪
Pre-Flight
  • Paper trade the exact deploy code
  • Backtest matches forward test directionally
  • Real fees wired into P&L
  • Reconcile positions on startup
06 ⚙️
Operations
  • Secrets in env vars, never in git
  • API keys trade-only, no withdrawal
  • Runbook for deploy, rollback, restart
  • Supervisor with auto-restart and backoff
07 💰
Capital
  • Start small, money you can lose this week
  • Define "working" before you go live
  • Scale up after weeks, not days
  • Set a threshold for when to intervene
08 ⚖️
Legal & Tax
  • Local rules on bot trading and derivatives
  • Tax treatment of your trading income
  • Trade log with timestamps, fills, fees
  • Get advice for your jurisdiction
